# Calculator 🧮

A simple and interactive Calculator project created using HTML, CSS, and JavaScript.

## 📌 About The Project

This project is a functional calculator that performs basic arithmetic operations such as addition, subtraction, multiplication, and division. It provides a clean user interface and smooth user interaction.

I created this project to practice my frontend development skills and improve my understanding of JavaScript logic, functions, and DOM manipulation.

## ✨ Features

- Basic arithmetic operations
- Addition, subtraction, multiplication, and division
- Clear and delete functionality
- Responsive design
- User-friendly interface
- Instant calculation results

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
